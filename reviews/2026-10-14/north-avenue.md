## How to run them

- Traffic: 100 link clicks in the last 7 days (sheet), about 14 a day.
- One test needs about 150 visitors per version, so 300 in total: about 3 weeks per test. Five separate tests would take about 15 weeks. Too slow, so bundle into 2 rounds.
- The live headline test already uses the Clarity labels T1-A / T1-B (scripts in the "LP A/B test" tab and on both pages). Use new labels so the data doesn't mix:
  - **Round 1 (about 3 weeks), first screen = T1 + T2.** Version B: new headline + one-line call-out + form in the first phone screen. Clarity labels **T2-A / T2-B**.
  - **Round 2 (about 3 weeks), form area = T3 + T4 + T5** on top of the Round 1 winner. Clarity labels **T3-A / T3-B**.
- Stop the current "$600+" test before Round 1 unless Scott can back the number up. It has only about 31 visitors per version after 5 days.
- Do the Fix first items (button text, reviews heading, page title) on both versions before Round 1, so they don't skew the result.
- Call it the way the sheet says: at 150+ visits per version, a lead of 3+ percentage points wins. Closer than that, run another week.
- No pre-qualifier: playbook says "not for competitive ones like college consulting, SAT/ACT" and "If CPL is already $45-50, don't". CPL is $42.80 (7d) and $53.75 (3d).
